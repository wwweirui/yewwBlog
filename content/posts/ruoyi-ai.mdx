# RuoYi AI 项目学习指引

> 全栈式 AI 开发平台 — 从入门到精通  
> 基于 RuoYi-Vue-Plus 演化，深度融合 LangChain4j + LangGraph4j 企业级 AI 框架

---

## 📚 总览

RuoYi AI 是一款**企业级全栈 AI 开发平台**，你可以把它理解为：

- **后端**：Spring Boot 3.5 + JDK 17 + MyBatis-Plus（传统企业级底座）
- **AI 核心**：LangChain4j 1.13.0 + LangGraph4j 1.5.3（多模型/多Agent/RAG/工作流）
- **前端**：Vue 3 + Element-Plus-X（独立仓库）
- **定位**：单体多模块 Maven 项目，非微服务

| 项目规模         | 技术栈广度         | AI 深度                 | 适用人群     |
| ---------------- | ------------------ | ----------------------- | ------------ |
| ~1000+ Java 文件 | 极高（全栈企业级） | 深（类 LangChain 生态） | 中高级开发者 |

## 阶段一：环境搭建与本地运行

### 1.1 依赖清单

| 组件   | 版本                   | 用途       | 学习重点                                          |

# 3. 访问验证

## 阶段二：Java 企业级底座（约 1-2 周）

### 2.1 项目模块结构理解

先花一天时间理解项目的**模块划分**：

```
ruoyi-ai
├── ruoyi-admin        ← 启动入口（唯一可执行模块）
├── ruoyi-common/      ← 24 个通用子模块（基础设施层）
│   ├── common-core      # 工具类、常量、基础实体
│   ├── common-mybatis   # MyBatis-Plus 配置 + 多租户
│   ├── common-redis     # Redisson 缓存 + 分布式锁
│   ├── common-satoken   # JWT + Sa-Token 认证
│   ├── common-web       # 全局异常、统一响应体
│   ├── common-chat      # AI 通用抽象（重点🌟）
│   ├── common-sse       # SSE 流式推送
│   └── ...
├── ruoyi-modules/     ← 5 个业务模块
│   ├── ruoyi-system     # RBAC 权限、字典、配置
│   ├── ruoyi-chat       # AI 核心（重点🌟）
│   ├── ruoyi-workflow   # 工作流
│   ├── ruoyi-aiflow     # AI 流程编排（重点🌟）
│   └── ruoyi-generator  # 代码生成器
└── ruoyi-extend/      ← 扩展服务（独立部署）
    ├── ruoyi-monitor-admin   # 监控
    └── ruoyi-snailjob-server # 分布式任务调度
```

> **⚠️ 关键约束**：业务模块之间禁止横向依赖，只能依赖 `ruoyi-common-*`

### 2.2 核心知识点（按优先级排序）

#### 优先级 ★★★（必须掌握）

| 知识点                   | 源码位置                                        | 学习要点                                                                      |
| ------------------------ | ----------------------------------------------- | ----------------------------------------------------------------------------- |
| **Spring Boot 自动配置** | `application.yml` + 各模块 `auto-configuration` | 了解 `@SpringBootApplication` 扫描机制、Maven profile 切换                    |
| **MyBatis-Plus**         | `ruoyi-common-mybatis`                          | `BaseMapperPlus`、分页、多租户拦截器、逻辑删除                                |
| **Sa-Token 认证**        | `ruoyi-common-satoken`                          | 登录流程（`AuthController.login`→`IAuthStrategy.login`）、JWT Token、权限注解 |
| **统一响应体**           | `ruoyi-common-web` → `R.java`                   | 前端后端的 `code/msg/data` 契约、全局异常处理                                 |

#### 优先级 ★★（重要）

| 知识点            | 源码位置              | 学习要点                                     |
| ----------------- | --------------------- | -------------------------------------------- |
| **Redisson 缓存** | `ruoyi-common-redis`  | 分布式锁 `@Lock4j`、`RedisUtils` 工具类      |
| **动态数据源**    | `application-dev.yml` | 多数据源配置（master/agent）、读写分离       |
| **多租户**        | `ruoyi-common-tenant` | `tenant_id` 字段注入、数据隔离               |
| **Hutool 工具库** | `ruoyi-common-core`   | `StrUtil`、`BeanUtil`、`CollUtil` 等常用工具 |

#### 优先级 ★（了解）

| 知识点     | 说明                                   |
| ---------- | -------------------------------------- |
| 代码生成器 | `ruoyi-generator` 可自动生成 CRUD 代码 |
| 工作流     | `ruoyi-workflow` 基于 Warm-Flow        |
| 文件存储   | `ruoyi-common-oss` 基于 S3 协议        |

### 3.3 关键源码文件（按学习顺序）

| 学习顺序 | 文件                                  | 说明                                                |
| -------- | ------------------------------------- | --------------------------------------------------- |
| 1️⃣       | `ChatServiceFactory.java`             | 工厂模式，理解如何动态发现所有模型实现              |
| 2️⃣       | `AbstractChatService.java`            | 模型抽象基类，理解模板方法模式                      |
| 3️⃣       | `OpenAIServiceImpl.java`              | 一个具体模型实现，了解 `buildStreamingChatModel()`  |
| 4️⃣       | `ChatServiceFacade.java`              | 统一门面，理解 SSE 流式对话的完整流程               |
| 5️⃣       | `VectorStoreStrategyFactory.java`     | 策略模式，理解向量库切换机制                        |
| 6️⃣       | `KnowledgeRetrievalServiceImpl.java`  | 高级 RAG 流水线，理解混合检索                       |
| 7️⃣       | `WebSearchAgent.java`                 | 声明式 Agent 定义，理解 `@Agent` + `@SystemMessage` |
| 8️⃣       | `SkillsAgent.java`                    | 技能加载，理解基于 Markdown 的技能系统              |
| 9️⃣       | `WorkflowEngine.java`                 | LangGraph4j 工作流引擎                              |
| 🔟       | `LangChain4jObservabilityConfig.java` | 全链路可观测性                                      |

### 3.4 核心设计模式

| 模式           | 应用位置                     | 理解要点                                     |
| -------------- | ---------------------------- | -------------------------------------------- |
| **工厂模式**   | `ChatServiceFactory`         | Spring 容器收集所有 modelType，通过 Map 路由 |
| **策略模式**   | `VectorStoreStrategyFactory` | 根据配置 type 选择不同的向量库实现           |
| **模板方法**   | `AbstractChatService`        | 固定流程骨架，子类实现模型构建               |
| **门面模式**   | `ChatServiceFacade`          | 统一对外接口，内部路由到不同 Provider        |
| **观察者模式** | 可观测性监听器               | 8 类 Listener 覆盖 AI 调用全生命周期         |

### 3.5 推荐练习

1. **追踪一次 AI 对话**：从前端 SSE 请求 → `ChatServiceFacade` → 模型调用 → SSE 返回，完整走一遍
2. **新增一个模型**：参考 `DeepseekServiceImpl`，新增一个模型提供商（如 Anthropic Claude）
3. **测试 RAG 检索**：上传一篇文档到知识库，查看向量化后的片段存储
4. **调试 Agent 调用**：启用思考模式（thinking mode），看 Supervisor 如何调度子 Agent
5. **理解 MCP 通信**：启动 Playwright MCP Server，看 Agent 如何调用浏览器工具

## 阶段四：高级特性（约 1-2 周）

### 4.1 AIFlow 可视化工作流

```java
// WorkflowEngine 核心逻辑
WorkflowGraph<String, WfState> workflow = new WorkflowGraph<>();
workflow.addNode("llm_answer", llmAnswerNode);
workflow.addNode("knowledge_retrieval", knowledgeNode);
workflow.addEdge("start", "llm_answer");
workflow.addEdge("llm_answer", "knowledge_retrieval");
```

**学习要点：**

- `StateGraph` 状态机管理
- `MemorySaver` 检查点（Checkpoint）机制
- SSE 流式推送节点执行状态
- 人机交互节点（HumanFeedback）的中断与恢复

### 4.2 可观测性

```java
// 8 类监听器覆盖全链路
- AiServiceListener    // AI 服务调用生命周期
- ChatModelListener    // 模型请求/响应追踪
- EmbeddingListener    // 嵌入请求追踪
- AgentListener        // Agent 执行追踪
- ToolListener         // 工具调用追踪
- MCPClientListener    // MCP 通信追踪
- GuardrailListener    // 安全护栏
- ErrorListener        // 异常追踪
```

**学习要点：** 如何通过监听器模式实现调用链追踪、日志记录、指标统计

### 4.3 扩展点

| 扩展点         | 实现方式                                | 示例                  |

## 🧠 常见问题 FAQ

### Q: 我不熟悉 Java / Spring Boot，能直接学 AI 部分吗？

**不能。** AI 模块（`ruoyi-chat`）完全构建在 Spring Boot 框架之上。必须先理解 Spring Boot 的 IoC/DI、AOP、配置体系、MVC 等基础概念。

### Q: 这个项目用的是什么 AI 框架？

**LangChain4j**（Java 版 LangChain）+ **LangGraph4j**（Java 版 LangGraph）。如果你熟悉 Python 的 LangChain，迁移学习会非常快，API 设计几乎一一对应。

### Q: 必须先装向量库吗？

**不需要。** 项目默认配置了 Milvus，但不装向量库不影响基本对话功能。RAG 知识库功能需要向量库时才需要部署。

### Q: 前端在哪？怎么启动？

前端是**两个独立仓库**，不在本项目内：

- 管理端：https://github.com/ageerle/ruoyi-admin（Vue 3 管理后台）
- 用户端：https://github.com/ageerle/ruoyi-web（Vue 3 对话界面）

### Q: 我想在生产环境使用，需要注意什么？

1. 关闭多租户（`tenant.enable: false`）或配置好租户策略
2. 关闭演示模式（`demo.enabled: false`）— 已默认关闭
3. 更换 Sa-Token 的 `jwt-secret-key`
4. 更换 API 加密的 RSA 密钥对
5. 关闭 Swagger（`springdoc.api-docs.enabled: false`）
6. 配置生产级 MySQL/Redis 连接池
