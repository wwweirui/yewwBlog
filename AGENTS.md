## Spec-Driven Development with LeanSpec

This project follows **Spec-Driven Development (SDD)** using **LeanSpec** — a lightweight,
tool-agnostic framework for managing specs that keeps each spec under ~2000 tokens
for efficient AI context usage.

- **Specs**: Each feature or task has a spec document in `specs/` directory
- **Lifecycle**: Draft → Review → Active → Done → Deprecated
- **Format**: Single markdown file (standard) or DESIGN.md + PLAN.md + TEST.md (detailed)

## Working with Specs

```bash
# Create a new spec
npx leanspec spec:create "feature-name" --template standard

# List all specs
npx leanspec spec:list

# Show spec status board
npx leanspec board

# View project health
npx leanspec stats
```

## Spec Format

```markdown
---
title: "Feature Name"
status: draft
tags: [enhancement]
created: "YYYY-MM-DD"
---

## Problem

What needs to be solved?

## Solution

How it will be solved.

## Tasks

- [ ] Task 1
- [ ] Task 2

## Notes

<!-- Additional context -->
```

## Committing Changes

1. Update spec status before committing
2. Ensure specs reflect what was actually built
3. Move completed specs to `status: done`
